Blockchain Explorer

Query Neo N3 network state, blocks, transactions, accounts, tokens, and contracts

🌐 Blockchain Information

Inspect the active network configuration, chain height, and validator information:

Network Status 
const networkMode = await tools.get_network_mode();

const blockchain = await tools.get_chain_info({
  chain: "n3",
  network: "mainnet"
});

const blocks = await tools.get_block_height({
  chain: "n3",
  network: "mainnet"
});

console.log("Mode:", networkMode.mode);
console.log("Available networks:", networkMode.availableNetworks);
console.log("Block count:", blocks.blockCount);
console.log("Latest height:", blocks.height);
console.log("Validators:", blockchain.validators);

🔗 Block Information

Query complete block details by numeric height or 64-character block hash:

Block Queries 
const blocks = await tools.get_block_height({ chain: "n3", network: "mainnet" });

const latestBlock = await tools.get_block({
  chain: "n3",
  hashOrHeight: blocks.height,
  network: "mainnet"
});

const blockByHash = await tools.get_block({
  chain: "n3",
  hashOrHeight: process.env.NEO_BLOCK_HASH,
  network: "mainnet"
});

console.log("Latest block:", latestBlock);
console.log("Block selected by hash:", blockByHash);

📄 Transaction Queries

Look up a transaction, inspect VM execution, and wait for confirmation when it is still pending:

Transaction Details 
const txid = process.env.NEO_TXID;

const transaction = await tools.get_transaction({
  chain: "n3",
  txid,
  network: "mainnet"
});

const applicationLog = await tools.get_application_log({
  txid,
  network: "mainnet"
});

const receipt = await tools.wait_for_transaction({
  txid,
  timeoutMs: 60000,
  pollIntervalMs: 3000,
  includeApplicationLog: true,
  network: "mainnet"
});

console.log({ transaction, applicationLog, receipt });

👤 Address Analytics

Inspect fungible-token balances, claimable GAS, and timestamp-filtered NEP-17 activity:

Address Information 
const address = "NZNos2WqTbu5oCgyfss9kUJgBXJqhuYAaj";

const balance = await tools.get_balance({
  chain: "n3",
  address,
  network: "testnet"
});

const unclaimedGas = await tools.get_unclaimed_gas({
  address,
  network: "testnet"
});

const transfers = await tools.get_nep17_transfers({
  address,
  fromTimestampMs: Date.now() - (7 * 24 * 60 * 60 * 1000),
  toTimestampMs: Date.now(),
  network: "testnet"
});

console.log({ balance, unclaimedGas, transfers });

Smart Contract State

Resolve a live contract, inspect its manifest, and execute a read-only method:

Contract Inspection 
const GAS_HASH = "0xd2a4cff31913016155e38e474a2c06d08be276cf";

const status = await tools.get_contract_status({
  contract: GAS_HASH,
  network: "mainnet"
});

const info = await tools.get_contract_info({
  chain: "n3",
  contract: GAS_HASH,
  network: "mainnet"
});

const symbol = await tools.call_contract({
  chain: "n3",
  scriptHash: GAS_HASH,
  operation: "symbol",
  args: [],
  network: "mainnet"
});

console.log({ status, info, symbol });

NFT Activity

Explore an address's NEP-11 holdings and timestamp-filtered transfer history:

NEP-11 Queries 
const address = "NZNos2WqTbu5oCgyfss9kUJgBXJqhuYAaj";

const balances = await tools.get_nep11_balances({
  address,
  network: "testnet"
});

const transfers = await tools.get_nep11_transfers({
  address,
  fromTimestampMs: Date.now() - (30 * 24 * 60 * 60 * 1000),
  toTimestampMs: Date.now(),
  network: "testnet"
});

console.log({ balances, transfers });
